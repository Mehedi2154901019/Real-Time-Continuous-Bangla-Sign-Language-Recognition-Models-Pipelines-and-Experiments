# Real-Time-Continuous-Bangla-Sign-Language-Recognition-Models-Pipelines-and-Experiments
Reproducible Bangla Sign Language recognition models pipelines covering static one-hand, static two-hand, and dynamic gestures. Includes source code, experimental configurations, documentation, and run instructions. Datasets are hosted on Zenodo and linked through persistent DOIs.

The three variants of Bangla sign language, i.e., static one-hand, static-two hand, and dynamic, gesture recognition with their complete source code, ablation studies, preprocessing, pipelines, etc are present in the three respective folders of the repository. Also, detailed instructions to understand and access every materials are included in the README.md files of the respective folders or directories of the repository.
